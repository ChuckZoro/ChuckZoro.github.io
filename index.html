Infrastructure · Security

Ubuntu Server Home Lab

A Docker-based home lab on Ubuntu Server 26.04, built and documented step by step. It hosts six containerized services behind a reverse proxy with HTTPS, uses my own DNS server, and is reachable remotely without opening a single firewall port.

  • Zero open ports. Remote access runs through an outbound Cloudflare Tunnel, and only the monitoring dashboard is exposed.
  • HTTPS everywhere. Nginx Proxy Manager routes traffic over a shared Docker network with TLS certificates.
  • Hardened SSH. Key-only login, with password and root login disabled.
  • Monitoring and alerts. Uptime Kuma watches every service and sends Telegram alerts when one goes down.

Why it matters for AI: I created a locked-down, key-only account so an AI agent can work on this server with limited privileges. Least-privilege access for AI agents is a core problem in AI security, and I've already practiced it.

About Me

From the service van to AI security.

Add a professional photo here Replace this box with an <img> element

Before cybersecurity, I worked as an HVAC and appliance technician. Every service call was an investigation: gather the symptoms, test each component, find the root cause, fix it, and explain it to a customer who just wanted their heat back.

AI systems need that same loop. Models fail in ways that aren't obvious, and finding out why takes patient, methodical testing. I'm making the move deliberately: earning CompTIA Network+, building a documented Docker home lab on Ubuntu Server, and working toward AI engineering and AI security.

I've also seen what happens when technology gets connected faster than it gets secured. The 2013 Target breach famously began with credentials stolen from an HVAC vendor. AI is being wired into business systems even faster today, and I want to be the person who builds it well and secures it properly.
